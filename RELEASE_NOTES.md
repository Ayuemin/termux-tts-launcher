# «Озвучить» v1.2.0 — стабильный выпуск с постоянной подписью

Android-лаунчер для чтения текста из буфера обмена голосом Microsoft Edge TTS через Termux.

### Главное в этом выпуске

- **Релиз теперь подписан постоянным релизным ключом**, а не отладочным. Это первый выпуск с настоящей подписью: с этого момента обновления можно устанавливать поверх предыдущей версии без переустановки.
- Подпись вводится начиная с **v1.2.0**. Предыдущий выпуск `v1.1.0` остаётся как есть и не перевыпускается.

### Что вошло

- Голос `ru-RU-DmitryNeural`, качество оригинального MP3 без перекодирования.
- Нажатие 1 — запуск, 2 — остановка (включая подготовку), 3 — новый запуск.
- Исправлен сбой `NoAudioReceived` после изменения протокола Microsoft: отдельная версия `edge-tts 7.3.1`, без обновления чужих Python-пакетов.
- Контроль задержек без записи текста; журнал событий ограничен объёмом.
- Удаление временных MP3 и уборка оставшихся после сбоев каталогов.
- Пошаговый README от установки Termux до настройки боковой панели.
- Лицензия MIT для кода проекта.

### Содержимое релиза

- **`ozvuchit-v1.2.0.apk`** — Android-приложение, подписанное постоянным релизным ключом.
- **`SHA256SUMS.txt`** — SHA-256 файла APK.
- Автоматические архивы исходников GitHub по тегу `v1.2.0`.

**Важно про подпись.** В этом выпуске ключ подписи изменился по сравнению с `v1.1.0` (там использовался отладочный ключ). Android не позволяет обновлять приложение, подписанное другим ключом, поэтому перед установкой v1.2.0 поверх v1.1.0 нужно **удалить только приложение «Озвучить»**. Ни Termux, ни Termux:API удалять нельзя. Все последующие обновления, начиная с v1.2.0, будут устанавливаться поверх без переустановки.

### Короткая установка обработчика для уже настроенного Termux

```bash
cd ~/termux-tts-launcher
git fetch --tags origin
git switch --detach v1.2.0
bash termux/install-launcher.sh
```

Для установки с нуля и настройки разрешений см. [README](https://github.com/Ayuemin/termux-tts-launcher/blob/v1.2.0/README.md).
