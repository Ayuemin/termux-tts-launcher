# «Озвучить» v1.1.0 — стабильный выпуск

Финальная версия Android-лаунчера для чтения текста из буфера обмена голосом Microsoft Edge TTS через Termux. Потоковая экспериментальная версия в выпуск не включена.

### Что вошло

- Голос `ru-RU-DmitryNeural`, качество оригинального MP3 без перекодирования.
- Нажатие 1 — запуск, 2 — остановка (включая подготовку), 3 — новый запуск.
- Исправлен сбой `NoAudioReceived` после изменения протокола Microsoft: отдельная версия `edge-tts 7.3.1`, без обновления чужих Python-пакетов.
- Контроль задержек без записи текста; журнал событий ограничен объёмом.
- Удаление временных MP3 и уборка оставшихся после сбоев каталогов.
- Пошаговый README от установки Termux до настройки боковой панели.

### Содержимое релиза

- **`ozvuchit-v1.1.0.apk`** — Android-приложение (выпуск для личной установки).
- **`SHA256SUMS.txt`** — SHA-256 файла APK.
- Автоматические архивы исходников GitHub по тегу `v1.1.0`.

**Важно про подпись:** APK собран CI и подписан **отладочным ключом**, это не Play Store / F-Droid production-signed пакет. При несовпадении подписи с ранее установленным APK для его замены нужно удалить **только приложение «Озвучить»**. Ни Termux, ни Termux:API удалять нельзя. Если старое приложение уже работает, APK менять не требуется — достаточно обновить Termux-обработчик.

### Короткая установка обработчика для уже настроенного Termux

```bash
cd ~/termux-tts-launcher
git fetch --tags origin
git switch --detach v1.1.0
bash termux/install-launcher.sh
```

Для установки с нуля и настройки разрешений см. [README](https://github.com/Ayuemin/termux-tts-launcher/blob/v1.1.0/README.md).

**Статус:** финальный стабильный выпуск. Разработка функциональности завершена.
