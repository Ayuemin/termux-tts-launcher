# «Озвучить» — Termux TTS Launcher

**Стабильный выпуск: v1.1.0 (14 октября 2026). Разработка завершена.**

Минимальное Android-приложение для озвучивания **скопированного текста** из боковой панели TECNO/HiOS и с обычного значка на экране. Работает через **Termux**, **Termux:API** и голос Microsoft Edge TTS `ru-RU-DmitryNeural`.

**Принцип:** скопировать текст → нажать «Озвучить» → слушать. Второе нажатие **останавливает** чтение (в том числе до начала звучания); третье **запускает заново**. Termux при каждом нажатии вручную открывать не нужно.

Скачать: **[GitHub Release v1.1.0](https://github.com/Ayuemin/termux-tts-launcher/releases/tag/v1.1.0)**.  
Состав выпуска: `ozvuchit-v1.1.0.apk`, `SHA256SUMS.txt` и исходный код по тегу `v1.1.0`.

> **О подписи APK.** Это зафиксированная версия для личной установки через GitHub Releases. APK подписан **отладочным Android-ключом сборки GitHub Actions**, а не постоянным ключом для магазина приложений. Подпись может отличаться от прежних APK. Если Android откажется устанавливать его поверх старого, удалите **только приложение «Озвучить»** и установите APK заново. **Termux, Termux:API и пользовательские данные не удаляйте.** Если прежний APK уже работает, заменять его необязательно: достаточно установить актуальный обработчик Termux.

## Установка с нуля

### 1. Установите Termux и Termux:API

На телефоне установите **оба приложения из одного источника**, например:

- [Termux — F-Droid](https://f-droid.org/packages/com.termux/)
- [Termux:API — F-Droid](https://f-droid.org/packages/com.termux.api/)

**Важно:** APK Termux и Termux:API должны быть с совместимой подписью. Не смешивайте F-Droid и GitHub-подписанные варианты. Если Termux уже настроен, **не переустанавливайте** его ради этого приложения.

Один раз откройте Termux и дождитесь завершения начальной настройки. Нужны Android 8.0+ и интернет. Root, Chrome, FFmpeg и Termux:Widget не требуются.

### 2. Установите обработчик озвучки

Все следующие команды выполняются в **обычном Termux**, не внутри Ubuntu/proot. На новой установке:

```bash
pkg update -y
pkg install -y git nano
git clone --branch v1.1.0 --depth 1 https://github.com/Ayuemin/termux-tts-launcher.git ~/termux-tts-launcher
bash ~/termux-tts-launcher/termux/install-launcher.sh
```

Установщик создаёт отдельную команду `tts-launcher-play` и устанавливает `edge-tts 7.3.1` в `~/.local/share/termux-tts-launcher/edge-tts-7.3.1/`. **Глобальную установленную версию `edge-tts` он не обновляет**. При первой установке могут быть добавлены отсутствующие системные зависимости Python. Существующая команда `tts` не заменяется и её настройки не трогаются.

Если каталог `~/termux-tts-launcher` **уже существует**, `git clone` не повторяйте. Используйте инструкции из раздела [«Обновление существующей установки»](#обновление-существующей-установки).

### 3. Проверьте плеер и синтез

```bash
termux-media-player info
printf 'Проверка озвучки. Всё готово к работе.' | tts-launcher-play
```

Ответ `No track currently!` на первую команду нормален, если звук сейчас не воспроизводится. После второй должна прозвучать фраза. Если нет — см. [диагностику](#если-не-работает).

### 4. Разрешите внешние команды Termux

Откройте настройки:

```bash
mkdir -p ~/.termux
nano ~/.termux/termux.properties
```

Добавьте или исправьте **одну** строку:

```properties
allow-external-apps=true
```

Если параметр уже равен `false`, **замените** его, не создавая дубликат. Сохранение в nano: **Ctrl+O → Enter → Ctrl+X**. Применение:

```bash
termux-reload-settings
```

При необходимости перезапустите Termux. Параметр позволяет внешним приложениям, которым вы отдельно предоставили разрешение `RUN_COMMAND`, выполнять команды в Termux. Не выдавайте такое разрешение посторонним приложениям.

### 5. Установите APK «Озвучить»

1. Откройте **[релиз v1.1.0](https://github.com/Ayuemin/termux-tts-launcher/releases/tag/v1.1.0)**.
2. В разделе **Assets** скачайте `ozvuchit-v1.1.0.apk` (не архив исходников).
3. Установите APK, если нужно — разрешите установку из браузера или файлового менеджера.
4. В Android откройте **Приложения → Озвучить → Разрешения → Дополнительные разрешения** и включите **Run commands in Termux environment** («Запуск команд в среде Termux»). На некоторых телефонах запрос появляется при первом запуске.

При ошибке несовпадения подписи APK см. предупреждение в начале README. Удалять Termux/Termux:API не нужно.

### 6. Добавьте кнопку в Smart Panel TECNO/HiOS

В редакторе боковой панели выберите обычное приложение **«Озвучить»**. Скопируйте любой текст, нажмите кнопку и дождитесь звука. Повторное нажатие остановит чтение; следующее снова начнёт его.

Лаунчер кратко получает фокус для чтения буфера обмена, передаёт текст через официальный `com.termux.RUN_COMMAND` и закрывается. Android может показать системное уведомление о чтении буфера.

## Обновление существующей установки

**Если всё уже работает, необязательно переустанавливать APK.** Для фиксации стабильного обработчика `v1.1.0`:

```bash
cd ~/termux-tts-launcher
git fetch --tags origin
git switch --detach v1.1.0
bash termux/install-launcher.sh
```

Проверьте, что библиотека установлена изолированно:

```bash
PYTHONPATH="$HOME/.local/share/termux-tts-launcher/edge-tts-7.3.1" python -c 'import importlib.metadata; print(importlib.metadata.version("edge-tts"))'
```

Ожидаемое значение: `7.3.1`. Если `git switch` сообщает о локальных изменениях, не удаляйте их принудительно; сначала сохраните свои файлы.

**Выпуск зафиксирован тегом `v1.1.0`**. Будущие изменения `main` или экспериментальной ветки на работу установленной версии не повлияют.

## Какие файлы остаются в Termux

Аудиофрагменты создаются только во **временных каталогах Termux** и удаляются штатно; при следующем запуске озвучки остатки временных папок этого приложения **старше 24 часов** очищаются. MP3 в «Загрузках» не сохраняются.

Статистика **не копится бесконечно**:

| Путь | Содержимое | Ограничение |
| --- | --- | --- |
| `~/.cache/termux-tts-launcher/last-timing.txt` | Последний замер задержки | Перезаписывается, а не дополняется |
| `~/.cache/termux-tts-launcher/last-events.log` | Служебные события | Очищается после превышения 16 КиБ |
| `~/.cache/termux-tts-launcher/active` | Текущий сеанс | Удаляется штатно или при следующем управлении |
| `~/.cache/termux-tts-launcher/active.lock` | Синхронизация | Маленький служебный файл |

Текст буфера и готовое аудио в журналах не сохраняются. Результаты замеров не отправляются разработчику.

Чтобы посмотреть диагностику после запуска:

```bash
cat ~/.cache/termux-tts-launcher/last-timing.txt
tail -n 25 ~/.cache/termux-tts-launcher/last-events.log
```

`first_audio_packet_ms` — время первого MP3-пакета от Microsoft; `first_audio_ready_ms` — время полной готовности первого фрагмента; `player_command_ms` — задержка команды плеера. Цифры отсчитываются от запуска Python, **без времени запуска самого Termux**.

## Если не работает

- **Нет звука даже при тесте из Termux:** убедитесь, что установлены приложение Termux:API и пакет `termux-api`; проверьте интернет/VPN.
- **`NoAudioReceived`:** старая `edge-tts 7.2.8` перестала работать после изменения протокола Microsoft в октябре 2026 года. Повторите установку обработчика из стабильного тега, чтобы включить отдельную `7.3.1`. Microsoft может менять протокол снова, поэтому постоянная работоспособность внешнего сервиса не гарантируется.
- **Звук из Termux работает, а кнопка — нет:** проверьте `allow-external-apps=true` и отдельное разрешение `RUN_COMMAND` для «Озвучить».
- **Второе нажатие не останавливает:** проверьте, что в Termux установлена именно команда `tts-launcher-play` из `v1.1.0`; при сомнительном состоянии посмотрите `last-events.log`.
- **Android прерывает фоновые процессы:** разрешите работу Termux и Termux:API без жёстких ограничений батареи.
- **Ошибки на длинном тексте:** передаваемый текст ограничен **96 КиБ UTF-8**; превышение не обрезается молча.

## Окончательная конфигурация проекта

- Android-приложение: `android/app/`, минимальный Java-код без сторонних Android-библиотек.
- Обработчик: `termux/tts-launcher-play`, голос `ru-RU-DmitryNeural`, библиотека `edge-tts 7.3.1`.
- Первое озвучиваемое предложение: фрагмент до 155 символов, остальные — до 650, максимум две параллельные задачи подготовки.
- Воспроизведение: **готовые временные MP3 через `termux-media-player`**; повтор неудачной генерации до трёх попыток.
- Остановка второго нажатия рассчитана на собственный звук, не на чужие аудиосеансы.
- **Экспериментальный HTTP-поток не входит в стабильный выпуск.** Его исходники остаются в отдельной ветке `feature/streaming-tts`, без планов объединения.
- Проект завершён на **v1.1.0**. Приведённые инструкции относятся к этой версии; нового функционала не планируется.
