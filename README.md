# Озвучить

Приложение для Android, которое читает вслух текст из буфера обмена. Используется русский голос Дмитрия от Microsoft. Можно запускать обычным значком или из боковой панели TECNO/HiOS.

**Как пользоваться:** скопируйте текст и нажмите «Озвучить». Повторное нажатие остановит чтение, следующее — запустит его заново.

## Установка на телефон с нуля

### Шаг 1. Установите Termux и Termux:API

Скачайте и установите оба приложения из F-Droid:

- [Termux](https://f-droid.org/packages/com.termux/)
- [Termux:API](https://f-droid.org/packages/com.termux.api/)

**Оба приложения должны быть из одного источника.** Откройте Termux и дождитесь завершения первоначальной настройки.

### Шаг 2. Выполните команды в Termux

Скопируйте и выполните последовательно:

```bash
pkg update -y
pkg install -y git nano
cd ~
git clone --branch v1.2.0 --depth 1 https://github.com/Ayuemin/termux-tts-launcher.git
bash ~/termux-tts-launcher/termux/install-launcher.sh
```

Дождитесь завершения установки. Скрипт сам установит необходимые компоненты для озвучивания.

### Шаг 3. Разрешите запуск из Android

В Termux выполните:

```bash
mkdir -p ~/.termux
nano ~/.termux/termux.properties
```

Добавьте в файл строку (если параметр уже есть, замените его, не создавая дубликат):

```properties
allow-external-apps=true
```

Сохраните: **Ctrl+O → Enter → Ctrl+X**. Затем выполните:

```bash
termux-reload-settings
```

Эта настройка разрешает подключённому Android-приложению запускать обработчик в Termux. Не предоставляйте разрешение на выполнение команд Termux неизвестным приложениям.

### Шаг 4. Установите «Озвучить»

1. [Скачайте APK «Озвучить» v1.2.0](https://github.com/Ayuemin/termux-tts-launcher/releases/download/v1.2.0/ozvuchit-v1.2.0.apk).
2. Откройте скачанный файл и установите приложение. Если телефон запросит разрешение на установку из этого источника, предоставьте его.

> **Обновление с версии 1.1.0:** начиная с v1.2.0 приложение подписано постоянным релизным ключом, а прежние сборки — отладочным. Android не позволяет установить обновление поверх приложения с другой подписью, поэтому для перехода с v1.1.0 нужно сначала удалить старую версию, а затем установить v1.2.0. Дальнейшие обновления будут ставиться поверх без переустановки.
3. Запустите «Озвучить». Если появится запрос **Run commands in Termux environment** («Запуск команд в среде Termux»), разрешите его. Если запроса нет, проверьте **Настройки Android → Приложения → Озвучить → Разрешения → Дополнительные разрешения**.

### Шаг 5. Начните пользоваться

Скопируйте текст в любом приложении и нажмите значок **«Озвучить»**. Для быстрого доступа добавьте его в боковую панель **Smart Panel** на TECNO/HiOS.

- Первое нажатие — начать озвучивание.
- Второе нажатие — остановить, даже если звук ещё готовится.
- Третье нажатие — начать заново.

## Если не работает

Проверьте интернет, установку **Termux:API** и разрешение **Run commands in Termux environment**. Если озвучивание прерывается в фоне, разрешите Termux и Termux:API работу без ограничений батареи.

## Важно

Для синтеза речи текст передаётся сервису Microsoft через интернет. Не используйте приложение для конфиденциальных текстов. Максимальный объём текста — 96 КиБ. Временные звуковые файлы удаляются автоматически, служебные журналы ограничены по размеру.

Исходный код и сведения о выпуске: [«Озвучить» v1.2.0](https://github.com/Ayuemin/termux-tts-launcher/releases/tag/v1.2.0).
