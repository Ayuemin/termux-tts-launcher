# «Озвучить» — Termux TTS Launcher

Android-приложение для озвучивания текста из буфера обмена голосом Microsoft Edge TTS **Дмитрий** (`ru-RU-DmitryNeural`). Работает с обычного значка приложения или из боковой панели TECNO/HiOS.

**Первое нажатие** — начать чтение. **Второе** — остановить, в том числе во время подготовки звука. **Третье** — начать заново. Открывать Termux перед каждым запуском не нужно.

## Установка с нуля

### 1. Установите Termux и Termux:API

Установите оба приложения **из одного источника**, например F-Droid:

- [Termux](https://f-droid.org/packages/com.termux/)
- [Termux:API](https://f-droid.org/packages/com.termux.api/)

Не смешивайте версии Termux и Termux:API из F-Droid и GitHub: их подписи могут быть несовместимы. Откройте Termux один раз и дождитесь первоначальной настройки. Нужны Android 8 или новее и интернет.

### 2. Установите обработчик в Termux

Все команды выполняйте в **обычном Termux**, не в Ubuntu/proot:

```bash
pkg update -y
pkg install -y git nano
git clone --branch v1.1.0 --depth 1 https://github.com/Ayuemin/termux-tts-launcher.git ~/termux-tts-launcher
bash ~/termux-tts-launcher/termux/install-launcher.sh
```

Установщик добавит необходимые зависимости и команду `tts-launcher-play`. Для этого приложения используется отдельная `edge-tts 7.3.1`; существующая команда `tts` не изменяется.

Если каталог `~/termux-tts-launcher` уже существует, **не выполняйте `git clone` повторно** — см. раздел [«Обновление»](#обновление).

### 3. Разрешите запуск команд из приложения

Откройте файл настроек Termux:

```bash
mkdir -p ~/.termux
nano ~/.termux/termux.properties
```

Добавьте или измените строку (без дубликатов):

```properties
allow-external-apps=true
```

В редакторе nano сохраните файл: **Ctrl+O → Enter → Ctrl+X**. Примените настройки:

```bash
termux-reload-settings
```

Этот параметр разрешает внешним приложениям с отдельным Android-разрешением `RUN_COMMAND` запускать команды Termux. Не выдавайте такое разрешение неизвестным приложениям.

### 4. Установите APK

1. Скачайте **[ozvuchit-v1.1.0.apk](https://github.com/Ayuemin/termux-tts-launcher/releases/download/v1.1.0/ozvuchit-v1.1.0.apk)** и установите его на телефон.
2. Если Android попросит разрешить установку APK из этого источника, подтвердите.
3. Откройте **Настройки Android → Приложения → Озвучить → Разрешения → Дополнительные разрешения** и включите **Run commands in Termux environment** («Запуск команд в среде Termux»). Названия пунктов могут отличаться; разрешение также может запрашиваться при первом открытии приложения.

**Важно:** APK подписан отладочным ключом сборки. Если Android откажется обновлять ранее установленную версию из-за несовпадения подписи, удалите **только «Озвучить»** и установите APK заново. **Не удаляйте Termux или Termux:API.**

### 5. Проверьте работу

В Termux выполните:

```bash
termux-media-player info
printf 'Привет. Проверка озвучки.' | tts-launcher-play
```

Ответ `No track currently!` на первую команду нормален, если ничего не играет. Вторая команда должна озвучить фразу.

Теперь скопируйте текст в любом приложении и нажмите значок **«Озвучить»**. На TECNO/HiOS его можно добавить в **Smart Panel**. Повторное нажатие остановит воспроизведение.

## Обновление

Если приложение уже работает, **APK переустанавливать необязательно**. Чтобы установить обработчик стабильной версии:

```bash
cd ~/termux-tts-launcher
git fetch --tags origin
git switch --detach v1.1.0
bash termux/install-launcher.sh
```

Если в репозитории есть ваши локальные изменения и Git не позволяет переключиться, сначала сохраните их.

## Если нет звука

- Проверьте интернет: синтез голоса выполняется на серверах Microsoft.
- Если не работает тест в Termux, убедитесь, что установлены приложение **Termux:API** и пакет `termux-api` (`pkg install termux-api`).
- Если тест в Termux звучит, а кнопка — нет, проверьте `allow-external-apps=true` и разрешение `RUN_COMMAND` для приложения «Озвучить».
- Если Android останавливает работу в фоне, снимите ограничения батареи для Termux и Termux:API.
- Для просмотра событий выполните:

```bash
tail -n 25 ~/.cache/termux-tts-launcher/last-events.log
```

## Что важно знать

- Голос обрабатывается онлайн: **не используйте сервис для конфиденциального текста**.
- Максимальный объём входного текста — **96 КиБ UTF-8**.
- Временные MP3 удаляются после воспроизведения; оставшиеся после аварийного закрытия каталоги старше суток очищаются при следующем запуске.
- Журнал событий ограничен по объёму, а файл измерений перезаписывается. Текст буфера и звук в журналы не записываются.
- Для работы не требуются root, Chrome, FFmpeg или Termux:Widget.

Исходный код и контрольная сумма APK доступны на [странице выпуска v1.1.0](https://github.com/Ayuemin/termux-tts-launcher/releases/tag/v1.1.0).
