# Termux TTS Launcher

**«Озвучить»** — маленькое Android-приложение для боковой панели TECNO/HiOS. Скопируйте текст, нажмите значок приложения, слушайте голос Microsoft Edge TTS. Termux открывать не требуется.

### Принцип

- Android Activity кратковременно выходит на передний план, читает текст из буфера обмена и отправляет его в `com.termux.RUN_COMMAND` через `EXTRA_STDIN`.
- В Termux отдельная команда `tts-launcher-play` преобразует текст в короткие MP3-фрагменты голосом `ru-RU-DmitryNeural` и воспроизводит их через `termux-media-player`.
- Первый фрагмент до 155 символов, остальные до 650. Следующие части подготавливаются в фоне (до двух одновременно).
- Используется Python-библиотека `edge-tts` без отдельных запусков CLI; адаптивная иконка без белых полей.
- **Никакого Chrome/Chromium, FFmpeg, Rich или сохранения результата в Downloads.** Для воспроизведения создаются только временные MP3 во внутреннем каталоге Termux, затем они удаляются.
- Другая команда `tts`, её скрипты, настройки и сохранённые аудиокниги не меняются.
- **Первое нажатие запускает, второе останавливает (включая подготовку), третье запускает снова.** Команда `tts` другого приложения не меняется. На другие сеансы воспроизведения `termux-media-player` команда остановки намеренно не нацелена.

## Установка

### 1. Termux

Требуются Termux (0.109+), Android-приложение **Termux:API** (той же подписи/источника, что Termux) и интернет. Установленный Termux:Widget не используется и не требуется.

В обычном Termux (не в proot Ubuntu):

```bash
pkg install -y git
cd ~
git clone https://github.com/Ayuemin/termux-tts-launcher.git
bash ~/termux-tts-launcher/termux/install-launcher.sh
```

Установщик при необходимости добавит только `python`, `termux-api`, `edge-tts` и **не тронет `tts`**. Для уже установленных зависимостей ничего скачивать не нужно.

Проверьте плеер (Termux:API должен быть установлен):

```bash
termux-media-player info
```

Для проверки новой команды (воспроизведёт тестовое предложение):

```bash
printf 'Проверка озвучки.' | tts-launcher-play
```

### Обновление уже установленной версии

После установки нового APK обнови и обработчик в Termux:

```bash
cd ~/termux-tts-launcher
git pull --ff-only
bash termux/install-launcher.sh
```

Проверка задержки до команды воспроизведения (без записи текста буфера):

```bash
cat ~/.cache/termux-tts-launcher/last-timing.txt
```

### Исправление: кнопка остановки перезапускает звук

Для обновления исправленного обработчика **APK переустанавливать не нужно**:

```bash
cd ~/termux-tts-launcher
git pull --ff-only
bash termux/install-launcher.sh
```

Если Android продолжает играть MP3 после неожиданного выхода Python,
обработчик сохраняет маркер сеанса и при следующем нажатии пытается остановить
именно этот фрагмент, а не заново озвучить скопированный текст.

Для диагностики без сохранения текста буфера:

```bash
cat ~/.cache/termux-tts-launcher/last-timing.txt
tail -n 25 ~/.cache/termux-tts-launcher/last-events.log
```

Показатель `first_audio_ready_ms` отсчитывается от запуска Python до готовности
первого MP3, а `player_command_ms` измеряет задержку запуска плеера.
Реальная задержка также зависит от сервиса Microsoft и сети.

### 2. Разрешение запуска сторонних команд

Откройте файл `~/.termux/termux.properties` и **добавьте или измените** строку:

```properties
allow-external-apps=true
```

Если уже есть `allow-external-apps=false`, измените его, а не добавляйте вторую строку. Выполните `termux-reload-settings` или перезапустите Termux.

**Внимание:** эта настройка разрешает запуск команд Termux внешним приложениям, которым вы выдадите отдельное Android-разрешение `RUN_COMMAND`. Не выдавайте такое разрешение неизвестным приложениям.

### 3. APK

GitHub → [Actions](https://github.com/Ayuemin/termux-tts-launcher/actions/workflows/build-apk.yml) → **Build Android APK** → успешный запуск → **Artifacts** → `termux-tts-launcher-debug-apk`. Скачайте архив с APK и установите файл `app-debug.apk` (при необходимости разрешите установку из выбранного источника).

В настройках Android → Приложения → **«Озвучить»** → Разрешения → Дополнительные разрешения (названия могут отличаться) разрешите **Run commands in Termux environment**. При первом открытии лаунчер также попробует запросить это разрешение.

### 4. Боковая панель TECNO

В редакторе Smart Panel добавьте обычное приложение **«Озвучить»**. Скопируйте текст и нажмите «Озвучить» для запуска. Повторное нажатие остановит речь; третье запустит снова. Даже пустой буфер не мешает остановке. Android может показывать стандартное уведомление об обращении к буферу. Лаунчер возвращает вас в исходное приложение.

## Важные ограничения

- Передаваемый текст ограничен **96 КиБ в UTF-8**. Больший текст отклоняется целиком (обрезания нет).
- Для работы нужен интернет, поскольку речь генерируется сервисом Microsoft. Не озвучивайте таким способом конфиденциальные материалы.
- Termux:API обеспечивает общий медиаплеер: сторонний вызов `termux-media-player play` прервёт текущий фрагмент. Внешний плеер мы не останавливаем намеренно.
- Android 16/HiOS может ограничивать фоновые операции. Рекомендуется не ограничивать работу Termux и Termux:API настройками батареи. Чтение буфера и запуск **должны быть проверены на устройстве** — эмулятора/Android-телефона в окружении CI нет.
- Debug APK из Actions пригоден для личной установки, **не** является подписанным релизом для магазинов.

## Проверка перед выпуском

- [ ] Сборка Android APK в GitHub Actions проходит.
- [ ] Первый запуск показывает запрос разрешения Termux, повторные — не показывают.
- [ ] Запуск из Smart Panel не открывает Termux.
- [ ] Непустой буфер запускает воспроизведение, пустой показывает ошибку.
- [ ] Текст больше 96 КиБ не обрезается и не отправляется.
- [ ] Русский текст озвучивается правильным голосом; длинный текст идёт фрагментами.
- [ ] Второе нажатие останавливает чтение, третье запускает; остановка возможна до начала звучания.
- [ ] Остановка не прерывает чужой звук; адаптивный значок без белых полос.
- [ ] В Downloads не появляются аудиофайлы; временные файлы удаляются.
- [ ] Команда `tts` другого приложения не изменена.

## Проект

- `android/` — минимальное приложение на Java без сторонних библиотек.
- `termux/tts-launcher-play` — отдельный Python-обработчик без браузера, FFmpeg и Rich.
- `termux/install-launcher.sh` — установка без удаления или изменения других TTS-программ.
- `tests/` — локальные проверки разбиения текста и команд управления.
- `.github/workflows/build-apk.yml` — автоматическая сборка debug APK.
